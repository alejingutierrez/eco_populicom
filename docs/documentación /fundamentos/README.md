# Fundamentos

Espacio transversal: las ideas y el vocabulario que todos los públicos comparten. Si
algo se usa en más de un espacio (un término, un concepto, una métrica), se define aquí
una sola vez y los demás documentos enlazan a esta sección.

## Contenido

1. [Qué es ECO](que-es-eco.md) — visión, para quién es, qué problema resuelve y cómo
   funciona a alto nivel.
2. [Glosario](glosario.md) — definición breve de cada término del producto.
3. [Conceptos clave](conceptos.md) — los pilares explicados: menciones y fuentes,
   sentimiento y emociones, pertinencia, tópicos, narrativas, crisis y geografía.
4. [Metodología de métricas](metodologia-metricas.md) — qué mide cada indicador, su
   rango y cómo leerlo (las fórmulas con código viven en la
   [Documentación Técnica](../tecnica/README.md)).

## Cómo leer este espacio

- Si es tu primer contacto con ECO, empieza por [Qué es ECO](que-es-eco.md).
- Si buscas el significado puntual de un término, ve directo al
  [Glosario](glosario.md).
- Si quieres entender *por qué* una métrica sube o baja, lee
  [Conceptos](conceptos.md) y [Metodología](metodologia-metricas.md).
