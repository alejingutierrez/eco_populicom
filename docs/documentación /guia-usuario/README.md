# Guía de Usuario

Cómo usar ECO en el día a día: iniciar sesión, navegar las pantallas, leer las métricas,
explorar menciones y narrativas, configurar alertas y reportes por correo, e interpretar
los insights de IA.

Esta guía explica **cómo se usa la herramienta**. Para entender **qué significan** las
cosas (qué es el NSS, qué es una narrativa, cómo se calcula el riesgo de crisis), consulta
los [Fundamentos](../fundamentos/README.md), a los que enlazamos a lo largo del texto en
lugar de repetir definiciones.

## Cómo navegar esta guía

- **Si es tu primera vez**, empieza por [Primeros pasos](primeros-pasos.md) y luego mira el
  [Overview](overview.md).
- **Si ya entraste y quieres analizar algo concreto**, ve directo a la pantalla que te
  interese (Menciones, Tópicos, Geografía, Narrativas).
- **Si algo no funciona como esperas** (no ves datos, los insights tardan, no recibiste el
  reporte), revisa las [Preguntas frecuentes](faq.md).

## Las dos vistas principales

ECO tiene dos pantallas de resumen, pensadas para necesidades distintas. Conviene tener
clara la diferencia desde el principio:

| | [Overview](overview.md) | [Scorecard](dashboard-scorecard.md) |
|---|---|---|
| **Para qué sirve** | Lectura rápida del estado de la conversación | Análisis táctico, métricas compuestas y drill-down |
| **Qué muestra** | Totales por sentimiento, serie diaria, top tópicos, top menciones | NSS, BHI, riesgo de crisis, engagement, anomalías, briefing ejecutivo, heatmap horario, mapa |
| **Equivale a** | El reporte semanal por correo, pero en pantalla | El "puesto de mando" del analista |

Ambas comparten el mismo [selector de período](primeros-pasos.md#selector-de-período) y el
mismo [selector de agencia](primeros-pasos.md#selector-de-agencia).
